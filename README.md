# Portafolio de Luis Felipe Anaya

Portafolio profesional bilingüe construido con React y Vite. Presenta experiencia, formación, proyectos aplicados y habilidades técnicas, con descarga del CV correspondiente al idioma seleccionado.

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm run build
```
